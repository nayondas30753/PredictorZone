PREDICTOR ZONE WEBSITE
======================

Files:
- index.html
- usdt-trc20-wallet-qr.png

Deployment:
1. Upload both files together to a GitHub repository (keep the QR image beside index.html).
2. In Cloudflare, open Workers & Pages -> Create -> Pages -> Connect to Git.
3. Select the repository and deploy as a static site.
4. No build command is needed. Use the repository root as the output directory.

Important:
- This is a static website. It does NOT receive or verify payments automatically.
- The customer must send USDT on TRC20 and share the transaction ID with you through a support channel.
- WhatsApp support: https://wa.me/message/GADTWUKBJ7ELH1
Telegram support: https://t.me/owner_predictorzone
- The QR code contains the wallet address only. Confirm TRC20 network and address before sending.
